# SanatanBhakti

A responsive, static, bilingual-ready starter website for puja vidhi, samagri, mantras, bhajan/path resources, ceremony gallery, enquiries, and source references.

Repository: https://github.com/anandmohantiwary/SanatanBhakti

## Publish with GitHub Pages

1. Upload the **contents** of this folder to the root of the `SanatanBhakti` repository (so `index.html`, `assets/`, `puja/`, etc. are at the repository root).
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for the deployment and open the URL shown in the Pages section. It will usually be `https://anandmohantiwary.github.io/SanatanBhakti/`.

## Included pages

- `index.html` — home page
- `puja/` — puja index and Satyanarayan Puja starter guide
- `library/` — samagri and mantra reference index
- `bhajan/` — bhajan and path resources
- `gallery/` — ceremony gallery placeholders
- `enquiry/` — enquiry form that prepares an email draft in the visitor's mail app
- `sources/` — editorial/source-reference policy

## Content accuracy

This is a starter package. Ritual content must be checked against named texts or published paddhatis and, where appropriate, reviewed by a qualified practitioner. The current pages intentionally distinguish starter content from verified ritual guidance. Do not present an item as universally authoritative when regional or sampradaya practices differ.

## Enquiry form limitation

The static enquiry form opens a prefilled email draft; it does not submit data to a server or store visitor details.
